1.4 Oct 9, 2026

Older iPads, a cleaner screen, no more blank pages

DashPad now runs on iPadOS 15, can hide the status bar, and tells you what went wrong when a dashboard won't load.

  • iPadOS 15 support. The iPad Air 2 and iPad mini 4 can run DashPad now.
  • Hide Status Bar. A new switch in Settings → Dashboard hides the clock, date, battery and Wi-Fi icons over your dashboard. It's on by default, and the idle screen always hides them.
  • Plain HTTP dashboards load again. Addresses like http://ha.home.lan:8123 used to show a blank screen. They work now (#4).
  • Clear error screen. When the dashboard can't load, you see "Can't reach dashboard" with the address and the reason, while DashPad keeps retrying every 10 seconds. Passwords in the address are never shown.
  • A home address blocked by Allowed Domains now says so, and loads as soon as you change the list.
  • A link that fails to load no longer replaces your dashboard.
  • DashPad reloads the page by itself if iPadOS stops the web view in the background.
  • Tapping a link no longer jumps back to the home page 10 seconds later.
1.3 Sep 15, 2026

A way to say thanks

A Rate DashPad row in Settings, for when you feel like it. The app never asks on its own.

  • Rate DashPad. A new row in the settings sidebar opens the App Store review page. Nothing happens unless you tap it: DashPad never pops up a rating prompt.
1.2 Aug 22, 2026

Back to 2017 iPads, and a smoother setup

Support for iPadOS 16 and a long list of fixes to the setup assistant, the camera permission and the PIN lock.

  • iPadOS 16 support. DashPad now runs on iPads back to the 5th generation (2017) and the original iPad Pro.
  • Setup assistant. Running it again from Settings keeps your dashboard address and presence mode instead of resetting them, and you can leave it with a Close button at any step.
  • Choosing a Custom URL for the idle screen during setup now asks for the address.
  • Address fields reject incomplete entries like http:// on its own.
  • Camera. The camera no longer starts while you're still in setup, so the permission prompt doesn't appear behind it and the screen doesn't dim mid-setup.
  • Declining camera access now really switches to Always Active, instead of the dashboard still dropping to the idle screen.
  • When camera access is off, DashPad explains why and where to change it, including when it's blocked by Screen Time or a management profile. The warning in Settings → Presence shows in every presence mode.
  • PIN lock. The entry screen shows four dots to match the four-digit PIN.
  • Reinstalling DashPad no longer leaves it locked by a PIN from a previous install.
  • Re-entering the same PIN during setup no longer gets stuck on that step.
1.0 Jun 29, 2026

First release

A full-screen kiosk browser that shows your dashboard when someone's in the room and rests when it's empty.

  • Kiosk browser. Full-screen web view that reloads by itself when the connection drops, with an optional list of allowed domains.
  • Three presence modes. Automatic uses the camera to detect someone in the room, entirely on-device. Schedule switches on and off at set times, with no camera at all. Always Active keeps the dashboard on.
  • Idle screen. A digital or analogue clock, a blank screen, or a web page of your choice, with separate brightness for active and idle.
  • Optional PIN lock for settings, with Face ID or device passcode as a fallback.
  • Settings open with a triple tap in the corner, and a setup assistant walks you through the first run.
